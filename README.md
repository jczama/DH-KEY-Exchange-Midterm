# DH-KEY-Exchange-Midterm


This project implements an authenticated finite-field Diffie-Hellman (FFDH) key exchange in Python 3. It utilizes custom algorithms for core mathematical operations, `pycryptodome` for prime generation, and `cryptography` for Ed25519 identity authentication, canonical JSON serialization, and message integrity checks.

---

## Prerequisites & Installation

This project works cross-platform on Windows, macOS, and Linux.

1. Ensure Python 3.10 or newer is installed (with IDLE selected during installation if on Windows/macOS).
2. Open your terminal (PowerShell, Command Prompt, or Terminal) in the project directory and install the required dependencies:
